# 欧盟 AI 监管追踪台（原型）

一个轻量级前端原型，用于支持“欧洲隐私合规专家”持续跟踪欧盟及成员国 AI 监管动态，重点突出隐私合规，同时覆盖竞争法、消费者保护、网络安全等领域。

## 功能概览

1. **AI 相关知识库**
   - 记录欧盟/成员国立法、监管指导、判例。
   - 对“隐私合规（重点）”进行视觉高亮。

2. **监管动态**
   - 记录新闻报道、立法进展、执法动态、监管声明。
   - 每条动态可录入业务影响与来源。

3. **分析报告**
   - **全局报告**：基于当前数据自动生成总体评估（风险、趋势、准备度）。
   - **时评**：对每条监管动态自动生成摘要与建议。

4. **需求澄清向导**
   - 内置关键澄清项清单，支持勾选进度。
   - 所有数据保存在浏览器 `localStorage`。

## 运行方式

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。
